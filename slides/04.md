## <span class="big">自分で出した数字は、仮定ではなく事実</span>

「生の体重の歪度は+7.60だった」―― これだけで通過する。

もう1つ惜しい例：「妊娠期間の歪度が**ほぼ０**なのに正規分布ではなかった」

## ④ そして、今日いちばん効くのがこれ

> 生のスケールの体重の**歪み**は **7.254** であった

- 歪度 **+7.60** … 分布の形を表す指標（**単位なし**）
- 平均−1SD **−7,254 g** … ありえない体重（**単位はg**）

7.254 という数字は、ノートのどこにもない。

## <span class="big">機械は数字を出す。それが何の数字かは言わない</span>

`df["体重g"].mode()` → `992.4`
―― 意味のある最頻値かどうかは、**画面には出てこない**。

**計算は機械に、判断は人間に。** 今日の課題B1は、ここを聞いている。

## 代表値をコードで（第2回の再現）

```python
df["体重g"].mean()      # 平均  → 5880.9
df["体重g"].median()    # 中央値 → 3006.0
df["体重g"].mode()      # 最頻値 → 992.4  ← ？
df["一腹産子数"].mode() # 最頻値 → 1.01   ← ？
df["科"].mode()         # 最頻値 → オナガザル科
```

電卓で出した値と**同じ**。違いは速さと正確さだけ。

---

## 最頻値 992.4 g ―― 計算は通る。では何を表す？

`.mode()` ＝ **データに最も多く記録されている値**

- 体重の記録がある265種のうち、992.4 g が **6種**でいちばん多い
- その6種は、いずれも**同じ Callicebus 属**（なぜ同じ値かはCSVからは不明）
- 連続量では、測定精度・丸め・まとめ方で「同じ値の回数」が変わる

<br>

中央値3,006 gから離れていること自体は誤りではない（歪んだ分布では普通）
**最多でも、分布の山や典型的な体重を表すとはかぎらない** → ヒストグラムも見る

> 第3回の偏差値159と同じ ――
> **計算が通ることと、その数字をどう読めるかは別**

---

## 一腹産子数 1.01 ―― 1行が何を表しているか

子の数なのに**小数**。この列は**種ごとに整理・調整された代表値**だから
（この表では1.01が**74種**。「1.01頭生まれる」ではない）

数えているのは**種**であって、**出産ではない**

<br>

### 同じ値が繰り返し現れる列なら、最頻値はそのまま読める

```python
df["科"].mode()          # → オナガザル科
df["科"].value_counts()  # → オナガザル科 132種
```

＝「この表にいちばん多く入っている科」と、そのまま解釈できる

---

## ばらつき・要約・集計

```python
df["妊娠期間日"].std()                  # SD → 37.8（日）
df["妊娠期間日"].var()                  # 分散 → 1427.2（日²）
df["体重g"].describe()                  # 一気に要約
df.groupby("科")["体重g"].mean()        # 科別平均
df.isna().sum()                         # 欠損の確認
plt.hist(df["体重g"].dropna())          # グラフ1行
```

手計算なら数十分 → **一瞬**

分散の単位は**2乗**（日²）。`.std()` / `.var()` の分母は既定で **n−1**

## まとめ

| やりたいこと | コード |
|---|---|
| 列を取り出す | `df["列名"]` |
| 平均/中央値/最頻値 | `.mean() .median() .mode()` |
| 標準偏差/分散 | `.std() .var()` |
| 要約 | `.describe()` |
| グループ集計 | `df.groupby("列")["列"].mean()` |
| 欠損 | `df.isna().sum()` |
