## ① いちばん多かったのは、これ

> **仮に**生の体重の歪度が正の値であれば、右に長い裾を持つ分布だと分かる

ノートには **+7.60** と出ている。なのに仮定の話にしてしまった。

## <span class="big">自分で出した数字は、仮定ではなく事実</span>

「生の体重の歪度は+7.60だった」―― これだけで通過する。

もう1つ惜しい例：「妊娠期間の歪度が**ほぼ０**なのに正規分布ではなかった」
指摘は今回いちばん鋭い。**−0.06 と書けばよかっただけ。**

---

## ④ そして、今日いちばん効くのがこれ

> 生のスケールの体重の**歪み**は **7.254** であった

- 歪度 **+7.60** … 分布の形を表す指標（**単位なし**）
- 平均−1SD **−7,254 g** … ありえない体重（**単位はg**）

7.254 という数字は、ノートのどこにもない。

## <span class="big">機械は数字を出す。それが何の数字かは言わない</span>

`df["体重g"].mode()` → `992.4`
―― 意味のある最頻値かどうかは、**画面には出てこない**。

**計算は機械に、判断は人間に。** 今日の課題B1は、ここを聞いている。

## エラーは失敗ではない

エラーメッセージ＝「ここが違うよ」という**お知らせ**

- `KeyError: '列名'` → 列名のスペル違い
- `SyntaxError` → カッコ・全角/半角・インデント
- 文字化け □□ → japanize のセルを実行したか

落ち着いて読めば、原因はたいてい書いてある。

## 代表値をコードで（第2回の再現）

```python
df["体重g"].mean()      # 平均  → 5880.9
df["体重g"].median()    # 中央値 → 3006.0
df["体重g"].mode()      # 最頻値 → 992.4  ← ？
df["一腹産子数"].mode() # 最頻値 → 1.01
```

電卓で出した値と**同じ**。違いは速さと正確さだけ。

---

## 最頻値 992.4 g ―― 動くけれど意味が出てこない

中央値は **3,006 g** なのに、最頻値は **992.4 g**。真ん中から遠い

### なぜ？

265種のうち **992.4 g がたまたま6回**出てきただけ
体重はほぼ連続量 → 255通りの値のうち2回以上出るのは6つだけ

<br>

いっぽう **一腹産子数の 1.01** は意味がある
209種のうち74種がこの値 →「ふつう一度に1頭産む」

<br>

### 最頻値が使えるのは、同じ値が繰り返し現れるデータ

> 第3回の偏差値159と同じ ――
> **計算が通ることと、意味が通ることは別**

## ばらつき・要約・集計

```python
df["妊娠期間日"].std()                  # SD → 37.8
df["体重g"].describe()                  # 一気に要約
df.groupby("科")["体重g"].mean()        # 科別平均
df.isna().sum()                         # 欠損の確認
plt.hist(df["体重g"].dropna())          # グラフ1行
```

手計算なら数十分 → **一瞬**

---

## まとめ

| やりたいこと | コード |
|---|---|
| 列を取り出す | `df["列名"]` |
| 平均/中央値/最頻値 | `.mean() .median() .mode()` |
| 標準偏差/分散 | `.std() .var()` |
| 要約 | `.describe()` |
| グループ集計 | `df.groupby("列")["列"].mean()` |
| 欠損 | `df.isna().sum()` |
