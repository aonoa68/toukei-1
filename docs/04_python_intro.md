!!! warning "② 因果が逆 ―― 「正規分布を当てはめたから歪む」"

    「平均±1SDに約68%」という読み方ができない（下限が−7,254gという、ありえない値になる）

    SDが40gになることはある。
    見分けるには、**値の散らばり方そのものを確かめる**しかない。ヒストグラム（今日の `8. グラフを1行で`）・

## 1. データは「表」＝ DataFrame

CSVを読み込むと、Excelのような表になる。Pandasでは、このような表形式のデータを **DataFrame** として扱い、慣習的に `df` という名前を付ける。

```python
df = pd.read_csv(URL)     # 表を読み込む
df.shape                  # (行数=種数, 列数)
list(df.columns)          # 列名の一覧
df.head()                 # 先頭5行
```

「行＝1つの種」「列＝体重・妊娠期間などの項目」。これがデータ分析の基本の形だ。

## 3. 代表値をコードで（第2回の再現）

第2回で手計算した3つの代表値は、メソッド1つで出る。

```python
df["体重g"].mean()        # 平均   → 5880.9
df["体重g"].median()      # 中央値 → 3006.0
df["体重g"].mode()        # 最頻値 → 992.4   ← この値の読み方に注意
df["一腹産子数"].mode()   # 最頻値 → 1.01    ← これも読み方に注意
df["科"].mode()           # 最頻値 → オナガザル科
```

第2回で電卓を叩いて出した値と、同じになるはず。**違いは速さと正確さだけ。**

!!! warning "最頻値が 992.4 g ―― 計算は通る。では、何を表しているのか"
    `.mode()` が返すのは、**データに最も多く記録されている値**である。体重のような連続量では、
    測定の精度や丸め、データのまとめ方によって、同じ値が何回現れるかが変わる。

    このデータでは、体重の記録がある265種のうち 992.4 g が **6種** でいちばん多かった
    （255通りある値のうち、2回以上現れるものは6つしかない）。
    その6種は、いずれも**同じ Callicebus 属**である。なぜ同じ値になっているのかは、
    このCSVだけでは分からない（元の文献が共通、まとめ方、丸め……いろいろ考えられる）。

    中央値 3,006 g から離れていること自体は、誤りの証拠ではない。歪んだ分布では、
    中央値と最頻値が別の位置を指すのは普通のことである。言えるのは、
    **992.4 g がいちばん多く記録されていても、それが体重分布の山や典型的な体重を表すとはかぎらない**ということだ。
    ヒストグラムなども確かめて判断しよう。

    第3回の偏差値159と同じで、**計算が通ることと、その数字をどう読めるかは別**である。

!!! note "一腹産子数が 1.01 ―― 1行が何を表しているか"
    `一腹産子数` の最頻値は **1.01**。子の数なのに小数になるのは、この列が
    **種ごとに整理・調整された代表値**だからである（出典のPanTHERIAは、複数の文献の値を
    条件をそろえてから、種ごとに1つの値にまとめている）。この表では1.01が **74種** に記録されている。

    だから「1.01頭生まれる」という意味ではない。また、ここで数えているのは**種**であって
    出産そのものではないので、この集計だけで「霊長類の出産はふつう1頭」を直接確かめたことにもならない。
    **数値を解釈するときは、1行が何を表しているかにも注意する。**

    いっぽう、同じ値が繰り返し現れる列なら、最頻値はそのまま読める。`df["科"].mode()` は **オナガザル科**
    （`df["科"].value_counts()` で数えると132種）。これは「この表にいちばん多く入っている科」と、そのまま解釈できる。

## 4. ばらつきをコードで（第3回の再現）

```python
df["妊娠期間日"].std()   # 標準偏差 → 37.8（日）
df["妊娠期間日"].var()   # 分散     → 1427.2（日²）
```

第3回の「SD ≈ 37.8日」がそのまま出る。分散はSDを2乗した量なので、**単位も2乗**になって 1,427.2 **日²** である。
数字だけでなく単位まで一緒に見る、という第3回の約束は、コードでも同じ。
なお `.std()` / `.var()` は、第3回で確認したとおり**既定で分母に n−1 を使う**（`ddof=0` と書けば n になる）。

## 6. グループごとに集計（groupby）

「科ごとの体重平均」のような**グループ別集計**は、`groupby` で書く。

```python
df.groupby("科")["体重g"].mean()
# ヒト科 70526 / オナガザル科 7829 / クモザル科 7127 …
```

`groupby("グループにする列")["集計する列"].集計関数()` という形。これは第9回（分散分析）への布石でもある。

## 7. 欠損を確認

```python
df.isna().sum()   # 列ごとの欠損(値が記録されていない)の数
# 初産日齢: 273 / 出産間隔日: 267 / 新生児体重g: 259 …（体重gですら111種が空欄）
```

**本物の研究データは、こういう姿をしている。**体重ですら111種が空欄で、初産日齢にいたっては273種が空欄である。
ここでいう「欠損」は、**このデータ表に値が記録されていない**という意味である（一度も測られていないのか、
文献から値を集められなかったのかまでは、この表からは分からない）。
現実の研究データには、こうした欠損が含まれていることが多い。

`.mean()` や `.describe()` は、**その列の欠損を除いて**計算される。今日の体重の平均 5,880.9 g は、
記録のある265種から出した平均である（`describe()` の count が265なのは、そのためだ）。
欠損している種に何か特徴があれば、**値がある種だけを集めた結果は、全体とずれる**可能性がある。
第6回で「この偏りが何を意味するか」を詳しく扱う。

## まとめ

| やりたいこと | コード |
|---|---|
| 列を取り出す | `df["列名"]` |
| 平均・中央値・最頻値 | `.mean() .median() .mode()`（`.mode()` は値の重複・丸めの影響に注意） |
| 標準偏差・分散 | `.std() .var()` |
| まとめて要約 | `.describe()` |
| グループ別集計 | `df.groupby("列")["列"].mean()` |
| 欠損の確認 | `df.isna().sum()` |
| ヒストグラム | `plt.hist(df["列"])` |

> 手で求めた値と、コードで求めた値は同じ。違うのは速さと正確さ。
> **計算は機械に任せ、人間は「どの数字を信じるか」の判断に集中する。**
> **コードは直感を持たない。だから直感が系統的に外れる場面でも、同じ手続きを同じ向きに実行する。第1回のモンティ・ホールを1万回試せたのは、飽きも思い込みもない相手だったからだ。**
