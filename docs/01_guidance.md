## 1. 直感は「なんとなく」間違えるのではない

人間の判断は速い。信号が青になれば渡るし、相手の表情で機嫌を読む。この速さは進化が与えた生存の道具だ。

問題は、その速さが**確率や大量データの前で系統的に裏切る**こと。ここでいう**系統的な偏り**とは、ある条件のもとで判断に一定の偏りが生じる傾向のことで、全員が毎回まったく同じ間違いをするという意味ではない。個々の判断には、その周りのばらつきもある。

偶然によるばらつきは、一定の条件（平均ゼロ・独立・有限の分散）のもとで、データを増やして平均すれば小さくなる。ただし有限回の平均でぴたりとゼロになるわけではない。一方、判断や測定の**仕組みに由来する偏り**は、同じやり方を繰り返すだけでは取り除けないことがある。この後者が**認知バイアス**にあたる。

代表的なもの（**ヒューリスティック**は判断を手早く済ませる方略であって、それ自体が誤りなのではない。特定の条件下で系統的な誤りにつながる、という関係にある）：

| 判断の方略・傾向 | 中身 | 例 |
|---|---|---|
| 代表性ヒューリスティック | 「典型的らしさ」で確率を判断する | リンダ問題（合接の誤謬） |
| 利用可能性ヒューリスティック | 思い出しやすい事例で頻度を見積もる | 飛行機事故を過大に怖がる |
| 確証バイアス | 自分の説を支持する情報ばかり集める | 「やっぱり◯◯だ」 |
| ギャンブラーの誤謬 | 偶然の偏りに「次は揺り戻す」と期待 | 「3連続で表、次は裏」 |

!!! quote "このコースの立場"
    日本社会で美徳とされる「空気を読む（同調）」も、データサイエンスの観点からは中立ではない。互いに影響し合えば、回答どうしに**依存**が生まれるからだ。

    ここで、よく混同される2つを分けておく。

    - **依存のあるデータから推測すること** …… できる。調査設計や依存の構造に合った方法を使えばよい（集落抽出などがその例）。
    - **依存のあるデータを、独立だとみなして分析すること** …… これが危ない。不確実性を見誤り、とくに正の相関があるときは**誤差を小さく見積もりすぎる**。

    平均そのものは、実は独立でなくても偏らない。各観測の期待値が \(\mu\) なら、期待値の線形性から \(E[\bar{X}] = \frac{1}{n}\sum_i E[X_i] = \mu\) である。問題は**平均の精度をどう見積もるか**のほうで、そこには観測どうしの共分散が効いてくる（→第6回）。

    なお、**社会的に同調しないことと、標本が統計的に独立であることは別の概念**である。「群れない」という態度が独立性を保証するわけではない。この授業の理念と、数学的な前提は、分けて理解してほしい。

## 2. 手を動かして「敗北」を確認する

講義で言葉を聞くだけでは直感は変わらない。**自分の目で外れるのを見る**必要がある。今日のColabノートで3つ確認する。

### ① モンティ・ホール問題

3つのドア、1つが当たり。あなたが1つ選んだ後、司会者がハズレのドアを1つ開ける。**ドアを変えるべきか？**

!!! note "前提（この条件でないと答えが変わる）"
    当たりの位置は3つのドアで等確率。司会者は**当たりの位置を知っていて**、毎回、あなたが選んでいない**ハズレのドアを必ず1つ開ける**。そのうえで必ず変更の機会を与える。司会者がどう開けるかは、この問題の確率構造そのものを決めている。

- 直感：「2択になったから 50:50。変えても同じ」
- シミュレーション（1万回）：**変えない 約33% / 変える 約67%**

これは実は、計算だけで先に分かる。**最初にハズレを選んでいれば、変更すれば必ず当たる**からだ。よって

\[ P(\text{変更して当たる}) = P(\text{最初の選択がハズレ}) = \frac{2}{3} \]

シミュレーションは、この結論を目で確かめるためのものである。

### ② 誕生日のパラドックス

23人いれば、誕生日が同じペアがいる確率は **約51%**（半分以上！）。

!!! note "前提"
    うるう日を除く365日が等確率で、各人の誕生日は互いに独立、と仮定する。これは現実の誕生日分布を調べて得た数値ではなく、**この確率モデルのもとでの値**である。理論値は \(1-\prod_{k=0}^{22}\frac{365-k}{365} = 0.5073\ldots\)。

直感が小さく見積もるのは、「**自分と**同じ人」を探してしまうから。本当は「**誰かと誰か**が同じ」で、ペアの数は \(n(n-1)/2\)、23人なら253通りある。人数のほぼ2乗で増えていく、という感覚が直感には無い。

### ③ 少数は偶然に振り回される（大数の法則）

公平なコインを独立に投げ続けると、表の割合は長期的に 0.5 へ収束する。ただし**1回投げ足すごとに必ず0.5へ近づくわけではなく**、途中で離れることもある。

正確に言うと、試行回数が少ないうちは**割合のばらつきが大きい**。少数でも偶然ちょうど半々になることはあるし、大きく偏ることもある。少ないデータで「傾向がある」と判断すると、ただの偶然を意味だと勘違いする。これは第3回のギャンブラーの誤謬（「3連続で表なら次は裏」）と区別すべき点でもある。

!!! quote "敗北のあとに何が残るか"
    今日は「直感が外れる」ところばかりを見た。だが、**直感が外れることと、あなたが判断できないことは別だ。**

    モンティ・ホールの答えは、条件を整理すれば**計算だけで出せる**。シミュレーションは、その結論を自分の目で確かめる手段だ。誕生日のパラドックスも同じで、理論値が先にあり、1万回2万回はそれを裏づける。

    だから正確にはこう言うべきだ。外れうるのは直感で、外れにくいのは**前提を書き出して計算する手続き**のほうである。ただし、**前提やプログラムが間違っていれば、回数をいくら増やしても正しい答えにはならない**。回数は正しさを保証しない。保証するのは、前提を明示して検算できるようにしておくことだ。

    この授業は、直感を責めるためにあるのではない。**直感が届かないところまで届く道具を、自分の手に持つため**にある。この14回が終わるとき、あなたは「なんとなくそう思う」の代わりに「こう確かめた」と言えるようになる。**群れず、データに基づき、自分で決める** ―― 第14回でここに戻ってくる。
